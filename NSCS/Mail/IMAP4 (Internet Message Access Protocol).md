Ermöglicht die Verwaltung der E-Mails am Mail-Server. Zugriff auch auf verschiedene Ordner innerhalb der Mailbox möglich.

Teilweise werden nur Teile des Standards unterstützt.
#### Vorteile
- Nachrichten werden auf dem Server gespeichert
- Schneller Zugriff auf Posteingang
- Posteingang immer auf dem neuesten Stand
#### Nachteile
- Für jede Nachricht muss eine Verbindung aufgebaut werden
- Für eine Kopie muss diese 2 mal hochgeladen werden
- Höhere Serverbelastung
### IMAPS
IMAPS ist die Verschlüsselte Version von IMAP und läuft auf dem Port 993.
